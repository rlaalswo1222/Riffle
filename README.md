# Riffle

합주하는 소리를 듣고, 내 악보에서 **지금 연주 중인 마디를 실시간으로 짚어 주고 페이지를 미리 넘겨 주는** 안드로이드 앱이다.

녹음 버튼을 누르고 연주를 시작하면 끝이다. 도돌이표·1·2번 괄호·D.S./Coda를 읽어 실제 연주 순서대로 따라가고, 페이지 끝에 다다르기 전에 다음 쪽을 띄워 둔다. 위치가 틀렸으면 지금 치는 마디를 한 번 누르면 거기서부터 다시 따라간다.

> 개인용 앱이다. 악보는 [악보바다](https://www.akbobada.com)에서 받은 PDF만 대상으로 한다.

## 어떻게 동작하나

### 1. 악보 읽기 (PDF 한 번 분석)

| 무엇 | 어떻게 |
|---|---|
| 마디 번호 | 각 줄 왼쪽에 인쇄된 번호를 PDF 글자 층에서 읽는다 |
| 마디선 | PDF에 들어 있는 **선 데이터**를 읽어, 양 끝이 오선 맨 윗줄·맨 아랫줄에 딱 맞는 세로선만 마디선으로 쓴다. 음표 기둥(3.5칸)과 괄호 갈고리는 자동으로 빠진다. 선 데이터가 없으면 렌더링 이미지에서 찾는다 |
| 도돌이표 | 악보 글꼴의 `.` 글자(도돌이 점) 위치 + 옆의 굵은 세로선. 점이 굵은 선의 왼쪽이면 끝(:‖), 오른쪽이면 시작(‖:) |
| 1·2번 괄호, D.S., To Coda, 𝄋, 𝄌, Fine | PDF 글자 층 |
| 코드 진행 | 오선 위의 코드 심볼(`F#m7`, `A/C#`, `N.C.` …)을 마디·박에 배정해 12음 크로마 템플릿으로 만든다 |
| 템포 | `♩=106` 같은 표시. 곡 중간에 바뀌면(`♩=196`) 그 마디부터 적용한다 |

이렇게 얻은 정보로 실제 연주 순서(예: `1–43 → 18–31 → 44–79`)를 펼친다.

### 2. 원곡 맞추기 (선택)

악보를 열면 유튜브에서 원곡을 찾아 받고, DTW로 악보 연주 순서에 맞춰 16분음표 단위의 기준 소리를 만든다. 코드 이름만 쓸 때보다 멜로디·음색까지 비교할 수 있어 훨씬 정확하다(실제 합주 녹음 기준 ±1마디 정확도 99.9%).

### 3. 실시간 따라가기

마이크 소리를 0.05초마다 12음 크로마로 바꿔 악보의 기준 소리와 비교한다.

- **예측:** 평소에는 템포대로 박을 진행시킨다.
- **보정:** 1초마다 최근 6초 소리로 위치·템포를 조금씩 바로잡는다. 화음이 오래 그대로인 구간에서는 지금 위치를 유지한다.
- **갈림길:** 도돌이처럼 순서가 갈리는 곳은 두 가설을 동시에 따라가다 소리로 판정한다.
- **길 잃음 복구:** 다른 위치가 꾸준히 더 잘 맞으면 그리로 옮긴다(원곡 기준 중앙값 약 5.6초). 같은 진행이 반복되는 먼 곳으로는 쉽게 튀지 않는다.
- **시작:** 같은 코드 진행이 반복되는 곡이 많아 곡 전체에서 위치를 찾지 않는다. 처음부터 / 누른 마디 / 멈춘 곳 근처에서 시작한다.

## 구조

```
lib/
  screens/
    library_screen.dart      악보 목록(홈)
    prep_screen.dart         악보 분석·원곡 찾기·시작 마디 고르기
    performance_screen.dart  녹음하며 따라가기, 자동 페이지 넘김
  services/
    local_score_analyzer.dart  마디 번호·괄호·D.S./Coda 읽기
    score_layout_detector.dart 마디선·도돌이 점 찾기(선 데이터 → 이미지 순)
    chord_chart.dart           코드 심볼 → 크로마 템플릿, 템포 변화
    reference_track.dart       원곡을 악보에 맞추기(DTW)
    chroma_stream.dart         마이크 PCM → 크로마
    score_follower.dart        실시간 위치 추종
  models/measure_map.dart      좌표 ↔ 마디, 연주 순서 펼치기
```

`server/`와 `home_screen`·`local_sync_screen`·`session_screen`은 예전 구상(여러 파트 악보를 마디로 연결)의 코드다. 지금 앱에서는 쓰지 않는다.

## 빌드

```bash
flutter pub get
flutter test
flutter run            # 안드로이드 기기(arm64)
```

- Flutter 3.x, 안드로이드 전용(마이크 녹음, 앱 안 yt-dlp로 원곡 받기)
- PDF 렌더링·글자·선 데이터: [pdfrx](https://pub.dev/packages/pdfrx)(PDFium)
- 글꼴: [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL, `assets/fonts/Pretendard-LICENSE.txt`)

## 한계

- 악보바다 PDF처럼 마디 번호·코드·도돌이 기호가 **글자로 들어 있는 PDF**만 읽는다. 스캔·캡처 이미지 PDF는 못 읽는다.
- 코드만으로 따라갈 때는 같은 진행이 반복되는 곳에서 헷갈릴 수 있다. 원곡을 맞춰 두면 훨씬 낫다.
- 원곡 다운로드는 개인 사용을 전제로 한다.
